# Step Up Year

A friendly catch-up app for children ages 5–10 who are behind in reading, writing and numbers. The goal is to help them move forward one small step at a time. It is a single `index.html` file with plain HTML, CSS and JavaScript, so there is nothing to install or build.

## What's inside
- 5 lands, 3 sections each, 5 short lessons per section (75 lessons)
- Ollie the owl: speaks instructions, shows captions, highlights words as they are spoken
- Hints, worked examples and a short "why" after answers
- A starter quiz to pick a starting land
- Practice Boost and Memory Check to revisit tricky or older skills
- Daily challenge, practice games, day streaks, stars, stickers
- Several learner profiles on one device
- Grown-up area: progress report, printable reward sheet, teacher mode, reset and remove (behind a grown-up question)

## Privacy
- All progress is stored in the browser's local storage on the device. Nothing is sent to GitHub or any server.
- Clearing the browser's site data erases progress, and progress does not move between devices.
- The page loads the Fredoka font from Google Fonts.

## Voices
- By default Ollie uses the device's own voice.

## Limits
- The lessons and hints were written for this app and have not been checked against a published curriculum. Please have a teacher or reading specialist review them.
- Mastery and review rules are simple defaults, not a validated assessment. They are only a rough guide.
- The one-year catch-up goal has not been evaluated.

## Run it locally
Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.
